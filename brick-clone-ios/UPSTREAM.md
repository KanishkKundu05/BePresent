BePresent is derived from [Foqos](https://github.com/awaseem/foqos) by Ali Waseem, under the MIT license. See [LICENSE](LICENSE).

Imported revision: `260d856b3504c30327585c9d1a7548c2a0e096aa`.

The upstream blocking strategies, models, scheduling, NFC/QR, Screen Time extensions, widgets, App Intents, and regression tests are retained. Internal Foqos symbols and source paths remain to make upstream comparisons easier. BePresent changes the app identity, app group, profile URL scheme, visible branding, theme, icons, and support screen.

The previous BePresent prototype is preserved in git at `652a81b`. Its local session format is not migrated into the upstream SwiftData schema; end any prototype blocking session before installing this replacement.
